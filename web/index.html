ANTES DE EMPEZAR

Lo esencial.

¿Necesito Obsidian o una IA?

No. Puedes organizar y registrar tu estudio por tu cuenta. Obsidian y las herramientas de IA son opcionales.

¿Dónde se guarda mi cuaderno?

La web lo guarda en el navegador de este dispositivo. Descarga una copia JSON y comprueba que puedes recuperarla: si borras los datos del navegador, podrías perder el cuaderno.

¿Puedo ayudar a mejorarlo?

Sí. El código es abierto y el proyecto está en pruebas. Puedes comunicar un problema o proponer una mejora con datos ficticios.
